# Engine Core is a two-slot canister engine: locked after first draw, Super Fuel inert to flight

The Engine Core used to bank anonymous charges — insert a canister, 60 units land in a port, the canister vanishes and the port is just a number. For Phase 2 that hides the two things the player must now reason about: which canister sits in which port, and that Super Rocket Fuel is not ordinary flight fuel. Decided: the Core exposes **two physical canister slots**; a Rocket Fuel canister banks charges and is consumed the instant its charge runs out; the first time the engines draw from a slot it **locks** — an untouched canister can be taken back out, but a locked one can never be removed by hand and is destroyed (not spilled) if the Core is broken. **Super Rocket Fuel in a slot never burns and never supplies flight charges** — it is inert until **Leave Planet** consumes exactly one such canister. Rejected: keeping the anonymous-charge model (Super Fuel would be indistinguishable from rocket fuel and could leak into ordinary flight); allowing partial canisters to be pulled (turns locked fuel into a carry-it-around exploit and a bookkeeping tax); Inserters loading Super Fuel (hand-only keeps the one deliberate, dangerous act deliberate). Consequence: breaking a Core with a half-burnt canister loses that fuel — deliberate, and the reason untouched-vs-locked must stay visible in the panel.
